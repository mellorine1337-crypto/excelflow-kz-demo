# ExcelFlow KZ
Локальный коммерческий MVP для анализа продаж из CSV/XLSX: сопоставление колонок, KPI, фильтры по датам/категориям/товарам, сравнение периодов, графики, ABC-анализ, продажи по дням недели, выводы и оформленный Excel-экспорт.

## Установка (macOS)
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python sample_data.py
streamlit run app.py
```
Загрузите `demo_sales.xlsx` через браузер. Если названия колонок отличаются, раскройте «Проверить сопоставление» в боковой панели.

## Тесты
```bash
.venv/bin/python -m pytest -q
```

## Быстрая демонстрация
1. Запустите приложение и нажмите «Открыть безопасное демо» либо загрузите `demo_sales.xlsx`.
2. Покажите автоматическое распознавание колонок и фильтры слева.
3. Выберите последние 30 дней, сравните с предыдущим периодом.
4. Откройте «Товары», затем скачайте `commercial_example_report.xlsx` как пример результата.

Подробный сценарий находится в `DEMO_GUIDE.md`, а план первых продаж — в `FIRST_CLIENTS_ALMATY.md`.

## Windows
Для первого запуска установите Python 3.12, затем дважды нажмите `Запустить_ExcelFlow_Windows.bat`. Подробности находятся в `QUICKSTART_WINDOWS.md`.

## Важно
- Валовая прибыль = выручка − себестоимость проданных единиц, без аренды, зарплат, налогов и других расходов.
- Не загружайте реальные клиентские данные на публичный Streamlit-сервер без аутентификации и согласования обработки данных.
- Файлы обрабатываются в памяти. История хранит только агрегаты при нажатии кнопки.
- Пока не поддерживаются возвраты, скидки, НДС, несколько валют и индивидуальные форматы выгрузок.

## Публичная демоверсия
Проект подготовлен для размещения на Streamlit Community Cloud. Перед публикацией прочитайте `DEPLOYMENT.md`. Публичная версия предназначена только для синтетических или обезличенных файлов: в приложении пока нет авторизации и отдельного защищённого пространства для каждого клиента.
